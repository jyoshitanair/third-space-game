#### Quick Overview
---
Dungeon is a work in progress game where you are able to play multiple levels as you search for rouge coins and the big jackpot in every level. 
Use your coins to get pets, new outfits, and more! there is also a player login!
Fight off enemies and try to make it to the end of each level - try not to let your health reach 0!

## HOW TO PLAY
* Create an account using our Talo Backend!
* Move using the Arrow Keys 
* You can not move past walls
* Reach the treasure chest at the end of the level to move on!
* There will be enemies to avoid soon! 
* There will be a shop to buy pets and outfits soon!
* More levels to be added soon!

1) You can collect coins and it gets stored in the backend! (tb fixed)
